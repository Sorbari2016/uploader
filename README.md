# File uploader

## Description:

File uploader is a stripped down version of Google drive (or One drive, or similar app). The purpose of building it is to 
- Work with ORMs (Object-Relational Mapping) tools/packages.
- Set up persistent session-based authentication.
- Use cloud storage service to upload files, as well as folders.
